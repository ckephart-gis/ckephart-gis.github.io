Town of Enfield GIS Modernization

As GIS Project Manager, I led the modernization of Enfield's parcel data infrastructure, cartographic standards, and public-facing web applications. Below are three recreations of that work using synthetic data: a cartographic annotation system, a Python rule-validation engine, and an interactive parcel viewer.

TOOLSArcGIS Pro, Python, Arcade, Experience Builder

The Work

Enfield's parcel data lived across disconnected systems with no shared standard for attributes, labeling, or validation. I re-engineered it into a centralized enterprise feature class governed by 33+ automated attribute rules, covering 16,000+ parcel records relied on across 7+ town departments. Alongside that, I built the cartographic standards to display it, the automation to keep it synchronized, and the public-facing tools for residents and staff to use it.

Component 1 / Cartographic Map

Feature-Linked Parcel Annotation

A scale-dependent, ADA-compliant annotation system built with Arcade expressions handling condominium stacking, missing-ID records, and unit substitution, so labels stay legible from a townwide overview down to a single block, with zero manual placement.

Synthetic parcel grid. Labels thin out automatically as you zoom, mirroring the real suppression logic.

Component 3 / Python Script

Parcel Attribute Rule Validator

The real system runs 33+ rules as Arcade attribute rules directly inside the geodatabase. This is a runnable Python recreation of the same rule logic, prototyped and tested the way the actual rules were before being ported into Arcade, checking required fields, zoning domains, condo/unit consistency, and NOID (no owner ID) handling.

Outcome

Zero manual label placement across 16,000+ parcels. New parcel splits and merges inherit correct labeling and pass validation automatically. Python and Arcade automation for popup configuration extraction eliminated several hours of manual work weekly, and a daily automated sync keeps parcel attributes aligned with the Assessor's system of record.

Tool / Web App

3D Print Cost Calculator

A single-file HTML/JS calculator for pricing custom 3D print orders, built to cost out multi-color print jobs on a Bambu P1S and compare four different pricing strategies before quoting a customer or a friend.

Overview

This tool grew out of pricing custom print orders (novelty ducks, coins, and keepsake models) where each job uses several filament colors at different price points. It rolls material, electricity, waste, and machine wear into one per-unit cost, then lets that cost feed into whichever pricing model fits the situation: raw cost, cost plus labor, a retail markup, or a lighter friends-and-family rate.

Stack

  • HTML5
  • CSS (custom properties)
  • Vanilla JavaScript
  • No build step / no dependencies

Key features

Per-color material cost

Add any number of filament colors with weight and price per kg; totals sum automatically.

Electricity and wear

Print time converts to hours, applied against configurable electricity and machine wear rates.

Four pricing models

Cost only, cost plus labor, retail markup multiplier, and a friends and family range.

Multi-print orders

Save several print jobs into one order and see a combined grand total under the active pricing model.

Try it
